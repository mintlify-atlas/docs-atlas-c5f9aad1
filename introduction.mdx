## What you can do with promptfoo

- **Evaluate prompts and models** — Run automated evals across any combination of prompts, models, and test cases. Review results in a terminal table or interactive web UI.
- **Red-team LLM apps** — Automatically probe your application for jailbreaks, prompt injections, data leakage, and other security vulnerabilities.
- **Compare models side-by-side** — Benchmark OpenAI, Anthropic, Google, Azure, Bedrock, Ollama, and [80+ other providers](/providers/overview) against each other on your own test cases.
- **Automate in CI/CD** — Run evals on every pull request to catch regressions before they reach production.
- **Score outputs automatically** — Define assertions (contains, regex, LLM-graded rubric, cost, latency, and more) that pass or fail each model response.

## How it works

Promptfoo uses a declarative YAML configuration file (`promptfooconfig.yaml`) to define your prompts, providers, and test cases. When you run `promptfoo eval`, it executes every combination and checks each output against your assertions.

```yaml
# yaml-language-server: $schema=https://promptfoo.dev/config-schema.json
prompts:
  - 'Convert the following English text to {{language}}: {{input}}'

providers:
  - openai:chat:gpt-5.5
  - openai:chat:gpt-5.4-mini

tests:
  - vars:
      language: French
      input: Hello world
    assert:
      - type: contains
        value: 'Bonjour le monde'
```

Results appear in your terminal as a pass/fail matrix and are stored locally so you can open them in the web UI at any time with `promptfoo view`.
