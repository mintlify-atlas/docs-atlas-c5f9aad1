This guide walks you through running your first LLM evaluation with promptfoo. You will install the CLI, scaffold a working example, run the eval, and inspect results—all in under five minutes.

<Steps>
  <Step title="Install promptfoo">
    Install the CLI globally with npm:

    ```bash
    npm install -g promptfoo
    ```

    Alternatively, use Homebrew (`brew install promptfoo`), pip (`pip install promptfoo`), or run any command without installing via `npx promptfoo@latest`.

    <Note>
      Requires Node.js `^20.20.0` or `>=22.22.0`. See [installation](/installation) for all methods.
    </Note>
  </Step>

  <Step title="Scaffold the getting-started example">
    Create the example project in the current directory:

    ```bash
    promptfoo init --example getting-started
    cd getting-started
    ```

    This downloads the [getting-started example](https://github.com/promptfoo/promptfoo/tree/main/examples/getting-started) from the promptfoo repository. The directory contains:

    - `promptfooconfig.yaml` — prompts, providers, and test cases
    - `README.md` — explanation of the example

    The configuration file looks like this:

    ```yaml promptfooconfig.yaml
    # yaml-language-server: $schema=https://promptfoo.dev/config-schema.json
    description: 'Getting started'

    prompts:
      - 'Convert the following English text to {{language}}: {{input}}'

    providers:
      - openai:chat:gpt-5.5
      - openai:chat:gpt-5.4-mini
      # - anthropic:messages:claude-sonnet-4-6
      # - google:gemini-3.1-pro-preview

    tests:
      - vars:
          language: French
          input: Hello world
        assert:
          - type: contains
            value: 'Bonjour le monde'
      - vars:
          language: Spanish
          input: Where is the library?
        assert:
          - type: icontains
            value: 'Dónde está la biblioteca'
    ```

    This config tests one prompt against two OpenAI models using two translation test cases. Each test case checks that the model output contains the expected translated phrase.
  </Step>

  <Step title="Set your API key">
    Most providers require an API key. For the default OpenAI providers in this example:

    ```bash
    export OPENAI_API_KEY=sk-...
    ```

    <Tip>
      You can also set keys in the `env:` block of your `promptfooconfig.yaml`. Never commit real keys to source control.
    </Tip>
  </Step>

  <Step title="Run the eval">
    From inside the `getting-started` directory, run:

    ```bash
    promptfoo eval
    ```

    Promptfoo sends each test case to each provider, evaluates the outputs against the assertions, and prints a results table in your terminal:

    ```
    ┌─────────────────────────────────────────────┬─────────────────┬─────────────────┐
    │ Prompt                                      │ gpt-5.5         │ gpt-5.4-mini    │
    ├─────────────────────────────────────────────┼─────────────────┼─────────────────┤
    │ French: Hello world                         │ ✓ Pass          │ ✓ Pass          │
    ├─────────────────────────────────────────────┼─────────────────┼─────────────────┤
    │ Spanish: Where is the library?              │ ✓ Pass          │ ✓ Pass          │
    └─────────────────────────────────────────────┴─────────────────┴─────────────────┘
    ```

    A green checkmark means the assertion passed. A red `✗` means it failed, and the output is shown inline so you can see what went wrong.
  </Step>

  <Step title="View results in the web UI">
    Open the interactive web viewer to explore outputs side-by-side:

    ```bash
    promptfoo view
    ```

    This starts a local server and opens your browser to a matrix view where you can compare outputs across models, filter by pass/fail status, and share results with your team.
  </Step>
</Steps>
