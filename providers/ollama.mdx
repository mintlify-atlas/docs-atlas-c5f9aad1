---
title: "Ollama local model provider setup"
description: "Run Llama, Mistral, Phi, Qwen, and other open-source models locally with Ollama and evaluate them in Promptfoo without sending data to external APIs."
---

The `ollama` provider connects Promptfoo to a locally running [Ollama](https://ollama.ai) server, enabling evals against open-source models without external API calls or data leaving your machine.

## Prerequisites

Install Ollama and pull the models you want to test:

```bash
# Install Ollama (macOS/Linux)
curl -fsSL https://ollama.ai/install.sh | sh

# Pull models
ollama pull llama3.3
ollama pull phi4
ollama pull qwen2.5
```

Ollama listens on `http://localhost:11434` by default.

## Provider string formats

| Format | API endpoint | Description |
|---|---|---|
| `ollama:chat:<model>` | `/api/chat` | Chat-formatted prompts (recommended) |
| `ollama:completion:<model>` | `/api/generate` | Raw text completion |
| `ollama:embeddings:<model>` | `/api/embeddings` | Embedding vectors |

```yaml
providers:
  - ollama:chat:llama3.3
  - ollama:chat:phi4
  - ollama:completion:llama3.2
```

## Basic configuration

```yaml title="promptfooconfig.yaml"
providers:
  - id: ollama:chat:llama3.3
    config:
      temperature: 0.7
      num_predict: 1024
      top_p: 0.9
```

## Changing the base URL

To use a remote Ollama server or a non-default port, set `OLLAMA_BASE_URL`:

```bash
export OLLAMA_BASE_URL=http://192.168.1.100:11434
```

Or per-provider in config:

```yaml
providers:
  - id: ollama:chat:llama3.3
    config:
      baseUrl: http://192.168.1.100:11434
```

## Thinking / reasoning mode

Some Ollama models support extended thinking. Enable it with the `think` parameter:

```yaml
providers:
  - id: ollama:chat:qwq:32b
    config:
      think: true
      num_predict: 4096
```

## Function calling

Models that support function calling (Llama 3.1+, Llama 3.3, Qwen 2.5) can use tools:

```yaml
providers:
  - id: ollama:chat:llama3.3
    config:
      tools:
        - type: function
          function:
            name: get_weather
            description: Get the current weather for a location
            parameters:
              type: object
              properties:
                location:
                  type: string
                  description: "City and state, e.g. Austin, TX"
              required: [location]
```

## Passing arbitrary Ollama parameters

Use the `passthrough` key for Ollama API parameters not directly surfaced in the config:

```yaml
providers:
  - id: ollama:chat:llama3.3
    config:
      passthrough:
        keep_alive: 5m
        format: json
```

## Comparing local models

```yaml title="promptfooconfig.yaml"
providers:
  - ollama:chat:llama3.3
  - ollama:chat:phi4
  - ollama:chat:qwen2.5:14b
  - ollama:chat:mixtral:8x7b

prompts:
  - "Explain {{topic}} in one paragraph."

tests:
  - vars:
      topic: quantum entanglement
  - vars:
      topic: the halting problem
```

## Environment variables

| Variable | Description |
|---|---|
| `OLLAMA_BASE_URL` | Server URL (default: `http://localhost:11434`) |
| `OLLAMA_API_KEY` | Optional Bearer token for authenticated Ollama servers |
| `REQUEST_TIMEOUT_MS` | Request timeout in milliseconds |
