Providers are the interfaces to language models and AI services in Promptfoo. They can be specified under either the `providers` or `targets` key in your configuration — the two keys are interchangeable. Each provider is identified by a string that encodes the API type and model name.

## Provider string format

Providers are specified using a colon-separated string that identifies the API type and model:

```yaml
providers:
  - openai:gpt-4o
  - anthropic:messages:claude-opus-4-6
  - google:gemini-2.5-pro
  - bedrock:us.anthropic.claude-opus-4-6-v1:0
  - ollama:chat:llama3.3
  - huggingface:chat:meta-llama/Llama-3.3-70B-Instruct
```

The general pattern is `<provider>:<model>` or `<provider>:<endpoint>:<model>` when you need to specify a particular API endpoint explicitly.

## Object format with configuration

To pass configuration options to a provider, use the object format with an `id` and `config` key:

```yaml
providers:
  - id: openai:chat:gpt-4o
    config:
      temperature: 0.7
      max_tokens: 1024

  - id: anthropic:messages:claude-opus-4-6
    config:
      max_tokens: 2048
      thinking:
        type: enabled
        budget_tokens: 8000

  - id: azure:chat:my-gpt4-deployment
    config:
      apiHost: myworkspace.openai.azure.com
```

## Authentication

Most providers read credentials from environment variables:

```bash
export OPENAI_API_KEY=sk-...
export ANTHROPIC_API_KEY=sk-ant-...
export GOOGLE_API_KEY=AIza...
```

You can also specify the key inline using the `apiKey` config option, which is useful when comparing multiple accounts or projects in one eval:

```yaml
providers:
  - id: openai:gpt-4o
    config:
      apiKey: sk-...
```

## Common configuration options

These options are supported across most providers:

| Option | Description |
|---|---|
| `temperature` | Controls output randomness (0.0 – 1.0) |
| `max_tokens` | Maximum tokens to generate |
| `top_p` | Nucleus sampling parameter |
| `frequency_penalty` | Penalizes repeated tokens |
| `presence_penalty` | Penalizes tokens already present in context |
| `stop` | Sequences that stop generation |
| `inputCost` | Override input token cost estimate |
| `outputCost` | Override output token cost estimate |

## File-based provider configuration

For complex setups, store provider config in a separate YAML file and reference it:

```yaml title="promptfooconfig.yaml"
providers:
  - file://providers.yaml
```

```yaml title="providers.yaml"
- id: openai:gpt-4o
  config:
    temperature: 0.7
- id: anthropic:messages:claude-opus-4-6
  config:
    max_tokens: 1000
```
