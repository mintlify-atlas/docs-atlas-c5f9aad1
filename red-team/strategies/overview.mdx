---
title: "Attack strategies for AI red teaming"
description: "Strategies augment base test cases by transforming prompts into adversarial variants, enabling broader and deeper coverage of LLM vulnerabilities."
---

Strategies transform the test cases generated by plugins into adversarial variants. Where plugins define *what* to test, strategies define *how* to attack — encoding prompts to evade filters, running iterative refinement loops, or escalating requests across multiple conversation turns.

## Available strategies

<AccordionGroup>
  <Accordion title="jailbreak:meta — iterative LLM-based jailbreaking">
    Uses a meta-agent attacker LLM to iteratively refine single-shot prompts until the target model complies. Each iteration analyzes the previous refusal and generates a more effective variant.

    ```yaml
    strategies:
      - id: jailbreak:meta
        config:
          numIterations: 20
    ```
  </Accordion>

  <Accordion title="jailbreak:tree — tree-based search">
    Explores a branching tree of prompt variations simultaneously, allowing it to find effective jailbreaks faster than linear iteration when the search space is large.

    ```yaml
    strategies:
      - jailbreak:tree
    ```
  </Accordion>

  <Accordion title="jailbreak:composite — composite jailbreaks">
    Combines multiple jailbreak techniques into a single prompt, stacking methods such as roleplay framing, encoding, and context manipulation for higher bypass rates.

    ```yaml
    strategies:
      - jailbreak:composite
    ```
  </Accordion>

  <Accordion title="jailbreak:hydra — multi-turn branching">
    Coordinates an attacker agent that branches across multiple conversational paths, remembers every refusal, manages backtracking automatically, and shares successful tactics across the scan.

    ```yaml
    strategies:
      - id: jailbreak:hydra
        config:
          maxTurns: 10
    ```
  </Accordion>

  <Accordion title="crescendo — gradual multi-turn escalation">
    Opens with benign questions and slowly escalates toward the target behavior across multiple turns, inspired by Microsoft Research's Crescendo paper.

    ```yaml
    strategies:
      - id: crescendo
        config:
          maxTurns: 5
          maxBacktracks: 5
    ```
  </Accordion>

  <Accordion title="goat — Generative Offensive AI Tester">
    Meta's GOAT research: an attacker LLM engages the target in dynamic multi-turn conversations, adapting its approach based on each response using structured observation, planning, and attack generation.

    ```yaml
    strategies:
      - id: goat
        config:
          maxTurns: 5
    ```
  </Accordion>

  <Accordion title="base64 — base64 encoding evasion">
    Encodes the adversarial prompt in base64 before sending, bypassing keyword-based safety filters that operate on raw text.

    ```yaml
    strategies:
      - base64
    ```
  </Accordion>

  <Accordion title="rot13 / hex / leetspeak — encoding variants">
    Alternative text encodings that similarly obscure adversarial content from pattern-based filters.

    ```yaml
    strategies:
      - rot13
      - hex
      - leetspeak
    ```
  </Accordion>

  <Accordion title="language — non-English testing">
    Generates test cases in one or more non-English languages. Safety training is often uneven across languages, making this an effective coverage gap.

    ```yaml
    redteam:
      language: ['es', 'fr', 'zh']
      plugins:
        - harmful
    ```
  </Accordion>

  <Accordion title="jailbreak-templates — static injection templates">
    Applies a library of known static jailbreak templates (e.g., DAN, roleplay prefixes) to every test case.

    ```yaml
    strategies:
      - jailbreak-templates
    ```
  </Accordion>

  <Accordion title="best-of-n — best-of-N sampling">
    Generates N varied phrasings of each adversarial prompt and sends all of them, selecting the response that best achieves the attack goal.

    ```yaml
    strategies:
      - id: best-of-n
        config:
          n: 5
    ```
  </Accordion>

  <Accordion title="citation — academic framing">
    Wraps prompts in academic or research citation contexts to make harmful requests appear scholarly.

    ```yaml
    strategies:
      - citation
    ```
  </Accordion>

  <Accordion title="homoglyph — visually similar character substitution">
    Replaces characters with visually similar Unicode look-alikes to bypass text-matching safety filters while remaining human-readable.

    ```yaml
    strategies:
      - homoglyph
    ```
  </Accordion>
</AccordionGroup>

## Specifying strategies in your config

Add strategies under the `redteam.strategies` key. Strategies apply to all plugins in the same config unless scoped otherwise.

```yaml
redteam:
  plugins:
    - harmful
    - pii
    - prompt-injection
  strategies:
    - jailbreak:meta
    - jailbreak:composite
    - base64
    - rot13
```

To pass configuration options, use the `id` + `config` form:

```yaml
redteam:
  strategies:
    - id: crescendo
      config:
        maxTurns: 10
        maxBacktracks: 5
    - id: goat
      config:
        maxTurns: 8
        stateful: false
    - id: jailbreak:meta
      config:
        numIterations: 30
```

<Tip>
Start with `jailbreak:meta` and `jailbreak:composite` for single-turn coverage. Add `crescendo` or `goat` when you need multi-turn coverage. Encoding strategies like `base64` and `rot13` are cheap to add and often catch filter gaps.
</Tip>

## Strategy costs

<Note>
Multi-turn strategies (`crescendo`, `goat`, `jailbreak:hydra`) make many API calls per test case. Run them on a smaller plugin set first, or use a cheaper provider, before running a full scan.
</Note>

| Strategy | Type | Relative cost |
|---|---|---|
| `base64`, `rot13`, `hex`, `leetspeak`, `homoglyph` | Encoding | Low |
| `jailbreak-templates`, `citation` | Template | Low |
| `best-of-n` | Sampling | Medium |
| `jailbreak:meta`, `jailbreak:tree`, `jailbreak:composite` | Iterative | Medium |
| `crescendo`, `goat`, `jailbreak:hydra` | Multi-turn | High |
