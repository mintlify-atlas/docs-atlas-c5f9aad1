Promptfoo is an open-source CLI and library for evaluating LLM applications and running automated red team security scans. Define test cases in YAML, run evals against any model, and catch regressions before they reach production.

## Why Promptfoo?

Promptfoo runs entirely on your machine — your prompts and data never leave your infrastructure. It integrates with CI/CD pipelines so quality gates catch regressions automatically on every pull request.

## Quick install

<CodeGroup>

```bash npm
npm install -g promptfoo
```

```bash brew
brew install promptfoo
```

```bash pip
pip install promptfoo
```

```bash npx
npx promptfoo@latest eval
```

</CodeGroup>

<Steps>
  <Step title="Initialize a project">
    ```bash
    promptfoo init --example getting-started
    cd getting-started
    ```
  </Step>
  <Step title="Set your API key">
    ```bash
    export OPENAI_API_KEY=sk-...
    ```
  </Step>
  <Step title="Run an evaluation">
    ```bash
    promptfoo eval
    promptfoo view
    ```
  </Step>
</Steps>
